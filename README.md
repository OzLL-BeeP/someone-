# ☠️ SOMEONE AI

A free, unrestricted AI assistant wrapper with a dark personality.

## Features
- Works in Termux & Linux
- Uses reverse-engineered Pollinations.ai API (free, no API key)
- Supports: DeepSeek, Gemini, Kimi-K2
- Prompt injection / jailbreak built-in
- Dark, edgy, unrestricted personality
- Caching support (like lmwrapper)

## Install (Termux)
```bash
pkg update && pkg upgrade
pkg install python3 git
git clone https://github.com/OzLL-BeeP/SOMEONE-AI
cd SOMEONE-AI
python3 setup.py
python3 -m someone.cli```
